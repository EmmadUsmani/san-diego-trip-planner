# Dev guide

## Run
```
pnpm install
cp .dev.vars.example .dev.vars        # APP_PASSWORD=dev, SESSION_SECRET=dev-secret (gitignored)
pnpm db:reset:local                   # migrate + seed the local D1 (.wrangler/state)
pnpm dev                              # Vite + Worker (workerd) on http://localhost:5173
```
Other scripts: `pnpm typecheck`, `pnpm lint`, `pnpm test` (Vitest unit + workerd integration), `pnpm test:e2e` (Playwright; resets + seeds DB, starts its own dev server on :5199, OSRM disabled), `pnpm build`, `pnpm db:generate` (after editing `db/schema.ts`), `pnpm db:migrate:local`, `pnpm db:seed:local`, `pnpm deploy`.
First real deploy: create the D1 DB (`wrangler d1 create sd-trip-planner`), put its id in `wrangler.jsonc`, `wrangler d1 migrations apply DB --remote`, seed with `wrangler d1 execute DB --remote --file db/seed.sql`, `wrangler secret put APP_PASSWORD` / `SESSION_SECRET`.

## Layout
- `shared/` pure TS (no src/ or worker/ imports; ESLint-enforced): `time` (LA tz, DST), `prayers`, `travel`, `range`, `schedule` (locked/booked rules, bucketing, leg specs), `weather`, `schemas` (zod), `types`. Import from the frontend as `@shared/...`.
- `worker/` Hono: `app.ts` (exports `type Api`), `routes/*`, `lib/*`, tests in `worker/test/`.
- `db/` schema, migrations, `seed-data.ts` (source of truth), `seed.sql` (generated by `db/make-seed.ts`).
- `src/` React. `src/routes/<Screen>.tsx` is one file per screen (screen agents own their file and may add sibling files/folders such as `src/routes/schedule/`). Router wiring is in `src/router.tsx`; don't edit it except to add routes.
- `e2e/` Playwright specs (`*.spec.ts`), helpers in `e2e/helpers.ts`.

## API (all JSON, `/api`; GET public, writes need the session cookie)
`POST auth/login {password}` / `GET auth/me` / `POST auth/logout` - `GET trip` (aggregate) - `GET|POST places`, `GET|PATCH|DELETE places/:id` - `GET ideas` - `GET|POST events`, `GET|PATCH|DELETE events/:id`, `POST events/:id/skip|unskip` - `GET legs?day=` - `GET weather` (503 if Open-Meteo is down) - `GET|PUT settings`.
Errors are `{ error, code? }` (`locked` / `booked` -> 409, validation -> 400/422, unauth -> 401). Door code is only included in `trip`/`settings` for logged-in users.
`GET trip` returns `{ days[{date, weekday, label, tzName, clocksFallBack, events, legs, prayers, batteryEndPct}], places (with eventCount), ideaIds, settings, range{points,lowPct,minPct,endPct,firstLow}, lodgingPlaceId, homePlaceId }`. Instants are UTC ISO strings; format with `@shared/time` (`formatTime`, `formatTimeCompact`, `laToUtc`, `laMinutesOfDay`, `snapInstant`, ...). Never use `toLocaleTimeString` without the LA zone.

## Frontend conventions
- Hooks in `src/api/hooks.ts`: `useTrip`, `usePlaces(category?)`, `usePlace(id)`, `useIdeas`, `useWeather`, `useSettings`, `useAuth`; mutations `useCreateEvent`, `useUpdateEvent({id, start?, end?, ...})`, `useDeleteEvent(id)` (unschedule), `useSkipEvent({id, skipped})`, `useCreatePlace`, `useUpdatePlace`, `useDeletePlace`, `useUpdateSettings`, `useLogin`, `useLogout`. Mutations invalidate trip/places/ideas/settings. Errors are `ApiError` (`status`, `message`, `code`); show `error.message`.
- `useCanEdit()` (`src/auth/useCanEdit`) -> boolean; disable edit controls when false and offer `useLoginDialog().openLogin()`.
- Search params: schemas in `src/lib/search.ts`; read with `getRouteApi("/schedule").useSearch()` and update with `navigate({ search })`. Don't import `router` from route files (circular).
- Styling: CSS variables in `src/styles/tokens.css` (Kit colors/radii), shared classes in `base.css` (`.card`, `.btn`, `.btn-primary`, `.chip`, `.field`, `.input`, `.muted`, `.stack`), CSS Modules per component. Icons in `src/components/icons.tsx`. Mobile breakpoint is 720px; the root layout already adds header/tab bar and `.page` padding (max 1360px).
- Add `data-testid="route-<name>"` roots (placeholders have them; keep them).

## Tests
- Unit/integration: `*.test.ts` next to code (`shared/`) or in `worker/test/` (workerd + D1 with migrations applied and the real seed reloaded before each test; outbound `fetch` throws unless mocked with `mockFetch`). Add `src/**/*.test.ts(x)` for frontend unit tests (node environment).
- E2E: add `e2e/<screen>.spec.ts`; projects `desktop` (1440x900) and `mobile` (390x844) both run every spec (skip with `test.skip(isMobile)`). Serial, one shared DB: call `reseed()` from `e2e/helpers.ts` in `beforeEach` of any spec that mutates data. Log in with `loginViaApi(page)` (fast) or `loginViaUi(page)`.
