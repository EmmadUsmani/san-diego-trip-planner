# Build spec — San Diego Trip Planner

Trip planner for Emmad + Ömer, La Jolla/San Diego, Sat Oct 31 – Tue Nov 3 2026. Desktop-first, good mobile viewing.
Design reference (match look & layout): `design/canvas/project/*.dc.html` (screens), `design/canvas/project/Kit.dc.html` (tokens/components), screenshots via `node design/tools/shot.mjs <File>.dc.html`. Real data (addresses, itinerary, backups, chargers, prayer/weather facts): `design/BRIEF.md` → DATA section.

## Stack (decided — don't change)
- Single pnpm package. React 19 + Vite + TypeScript (strict). `@cloudflare/vite-plugin` runs the Worker in workerd during `vite dev`.
- Frontend: TanStack Router (code-based or file-based routes, typed search params via zod), TanStack Query, dnd-kit, MapLibre GL (`maplibre-gl`, optionally `react-map-gl/maplibre`) with OpenFreeMap style `https://tiles.openfreemap.org/styles/positron`. Plain CSS (CSS modules or one tokens.css) using Kit tokens; fonts Bricolage Grotesque + Figtree (Google Fonts). No UI kit library, no Tailwind.
- Backend: Hono on Cloudflare Workers (one Worker serves the SPA via static assets + `/api/*`). D1 via Drizzle ORM; `drizzle-kit generate` → SQL in `db/migrations`, applied with `wrangler d1 migrations apply`. `drizzle-zod` for schemas. Hono RPC (`hc<Api>`) typed client in the frontend (type-only import of the worker).
- Layout: `src/` (React), `worker/` (Hono), `shared/` (pure TS domain logic + types used by both; imports nothing from src/worker), `db/` (schema, migrations, seed), `e2e/` (Playwright). Separate tsconfigs for app (DOM) and worker (workers-types).
- Tests: Vitest unit tests (shared/, components where useful), `@cloudflare/vitest-pool-workers` integration tests for API + D1, Playwright E2E against the dev server with a freshly migrated + seeded local D1. Scripts: `pnpm dev`, `pnpm build`, `pnpm test` (unit+integration), `pnpm test:e2e`, `pnpm typecheck`, `pnpm lint`, `pnpm db:migrate:local`, `pnpm db:seed:local`, `pnpm db:reset:local`, `pnpm deploy`.

## Domain
- **Time**: store instants as UTC ISO strings; display in `America/Los_Angeles` via Intl. DST ends Sun Nov 1 2:00 AM (Sat PDT, Sun–Tue PST) — must be correct everywhere; unit-test it.
- **Place**: id, name, category (`activity|food|charger|lodging|home`), address, lat, lng, neighborhood, tags (string[]: e.g. halal, halal-unconfirmed, indoor, outdoor), links ({label,url}[]), defaultDurationMin, hoursText, notes, createdAt/updatedAt. Every place has an address + coordinates.
- **Event** (schedule item): id, placeId (nullable for e.g. "Leave Valencia"), title, kind (`normal|booked|locked`), start, end, skipped (bool, for booked), chargeToPct (nullable; for charger visits), notes. Locked (check-in Sat 3 PM, check-out Tue 10 AM) cannot be moved/removed. Booked (Harbor Tour Sun 4:15–5:15) keeps its time but can be skipped/unskipped or removed. Normal events move freely. A place not referenced by any event is an "idea".
- **Prayer times**: computed in `shared/` with the `adhan` package, ISNA (North America) method, Airbnb coordinates, LA timezone. Fajr/Dhuhr/Maghrib emphasized, Asr/Isha light. Unit-test against: Sat 10/31 Fajr 5:57a Dhuhr 12:32p Asr 3:36p Maghrib 5:58p Isha 7:08p; Sun 11/1 Fajr 4:58a Dhuhr 11:32a Maghrib 4:58p (±2 min tolerance).
- **Travel legs**: between consecutive non-skipped events that have places (per day, plus the trip's start from home and end at home). `worker/` computes and caches legs in a `travel_legs` table keyed by (fromPlaceId,toPlaceId): try OSRM public API (`https://router.project-osrm.org/route/v1/driving/...`), else heuristic in `shared/travel.ts` (haversine × 1.3 road factor; avg speed 25 mph <3 mi, 35 mph <15 mi, 55 mph beyond; +3 min). Tests must not hit the network (mock fetch / force heuristic).
- **Geocoding**: Nominatim (`https://nominatim.openstreetmap.org/search`, send a User-Agent, ≤1 req/s) when a place is created without coordinates. Seed data must ship with coordinates (geocode once while writing the seed and hard-code them).
- **Range**: `shared/range.ts` — Tesla Model 3 Standard RWD 2026: 69.5 kWh usable, default 24 kWh/100 mi, EPA 321 mi. Battery % timeline from start charge (setting, default 90%) through legs in time order; charger events raise to chargeToPct. Low threshold 20%. Pure function, unit-tested.
- **Weather**: `GET /api/weather` fetches Open-Meteo (lat/lng of Airbnb, `timeformat=unixtime`, hourly precipitation_probability, temperature, weather_code; daily max/min/precip prob/weather_code) for 2026-10-31..2026-11-03, cached via Cache API ~1h. Convert to LA local times correctly across DST. If fetch fails return 503 and UI shows "Weather unavailable".
- **Settings**: key/value table (startChargePct, efficiencyKwhPer100Mi, homeLabel etc.).
- **Auth**: viewing is public; all mutations require a signed HttpOnly cookie set by `POST /api/auth/login` with the shared password (`APP_PASSWORD` secret; local `.dev.vars` with `APP_PASSWORD=dev` and `SESSION_SECRET=dev-secret`, gitignored, plus a committed `.dev.vars.example`). 90-day cookie; `GET /api/auth/me`; `POST /api/auth/logout`. Frontend shows a small "Log in to edit" affordance; edit controls disabled when logged out.

## Screens (match design)
Header nav: Overview, Schedule, Map, Places, Range (+ avatars E/Ö, login state). Mobile (<720px): bottom tab bar (Today, Schedule, Map, Places), layouts per `Mobile-*.dc.html`.
- **Overview** (`/`): hero (title, dates, countdown), Airbnb card (show/hide door code 8038 — only when logged in), 4 day cards (weather, hi/lo, rain %, plan list, prayer row, battery by night). Mobile: "Today" now/next view (based on current time; outside the trip show Day 1).
- **Schedule** (`/schedule?view=week|day&day=&drive=&prayers=&rain=`): week grid 4 AM–10 PM, Sat–Tue columns; events placed by time; drag (dnd-kit) to move (snap 15 min), drag from Ideas tray onto a day/time to schedule (uses place default duration, else 60 min), drag event back to tray to unschedule; resize not required. Locked: lock icon, not draggable. Booked: ticket icon, not draggable, Skip toggle. Drive-time rows between events (toggle), prayer lines in a right lane (toggle), hourly rain wash (toggle). Day view = single column. Mobile: day agenda with day picker.
- **Map** (`/map?day=`): MapLibre map, Airbnb pin, numbered stops for selected day with route line (Airbnb → stops → Airbnb; straight segments OK, OSRM geometry nice-to-have), layer toggles (Plan, Ideas, Food, Chargers), click a place → popup with distance/time from Airbnb + "Add to day" + "Details"; Measure tool: click two places/points → straight-line miles + estimated drive.
- **Places** (`/places`): search + filter chips; sections On the schedule (by day), Ideas, Food, Chargers; add/remove/add-to-day; "Add place" form (geocodes). **Place detail** (`/places/$placeId`): full page with details, edit form, mini map, scheduled card (change time / move to ideas).
- **Range** (`/range`): inputs start charge + efficiency (persisted to settings when logged in), chart of battery % over trip (SVG, no chart lib needed), legs list by day, chargers list.

- Loading/empty/error states. Accessible (labels, buttons, focus, contrast). Responsive at 1440 and 390.
